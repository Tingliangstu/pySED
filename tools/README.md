# Plotting helper scripts

The Aluminum and Silicon folders contain legacy standalone plotting scripts
that can be adapted for publication figures. Their bundled pySED 2.4 numerical
and image outputs were moved without modification to
`legacy/pySED-2.4/outputs/` and are checksum-indexed there.

For pySED 3.0 output, prefer `action = plot` and the plotting parameters in
the main manual. Treat these scripts as optional customization examples.
