peak_max_hwhm
~~~~~~~~~~~~~

**Syntax**

.. code-block:: text

   peak_max_hwhm = 0.1

**Meaning**
   Hard maximum for the fitted HWHM in THz.

**Default**
   ``1e6``.

**Notes**
   In most cases, this parameter does not need to be adjusted. Fits that reach
   it are flagged in the terminal.
