# Harmonic phonopy reference calculations

These Aluminum, Diamond, and Silicon folders contain lattice-dynamics helper
scripts and reference inputs. They are independent harmonic comparisons, not
pySED trajectory examples and not expected pySED 3.0 output.

Generated v2.4-era reference images were moved to
`../legacy/pySED-2.4/outputs/Ref_Phonon_dispersion_from_phonopy/`.
Run the scripts only after installing their documented external simulation and
phonopy dependencies, and compare structures, force models, and cells before
overlaying a harmonic branch on a finite-temperature SED map.
