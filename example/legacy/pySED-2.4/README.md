# pySED 2.4 example-output archive

This directory preserves 81 generated pySED 2.4 result files (70413502 bytes).
Files were moved from the material and tutorial folders without changing their contents.

The original paths are retained below `outputs/`. These files are historical-only:
their normalization and configuration interface predate pySED 3.0, so they are not
v3 expected results and must not be used as v3 numerical regression data.

- `MANIFEST.tsv` records path, byte size, and file type.
- `SHA256SUMS` records a SHA-256 checksum for every archived file.
